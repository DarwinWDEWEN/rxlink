# 控制台中文化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 `console.example.com` 的控制台界面显示中文，通过构建期替换上游产物里的英文字面量实现。

**Architecture:** 一个 vite 插件在 `transform` 阶段把 `@shlinkio/*` 产物与 `src/**` 里的英文字面量按字典替换成中文；`buildEnd` 阶段按预期出现次数校验，上游改文案则构建失败。运行时无变化。

**Tech Stack:** Vite 8 插件 API、Node 24（本机路径 `/Users/wang/.nvm/versions/node/v24.14.0/bin/node`）、JSON 字典、Playwright（验证）。

## Global Constraints

- **只翻界面文案**，不翻国家名 / 浏览器名 / OS 名（262 条数据值）。
- **字典必须人工审核**：剔除 `ASC`/`DESC`/`ArrowUp`/`Card.Body` 这类逻辑 key，只留真正显示给用户的文案。
- **不 fork 上游源码、不改上游包版本**。
- 默认构建出中文；`I18N_LANG=en` 出英文原版（回退）。

```js
// 扫描上游产物，统计候选 UI 文案的出现次数，产出 expected.json。
// 上游升级后重跑本脚本即可刷新基准。
import { readFileSync, writeFileSync, readdirSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { dirname, join } from 'node:path';

const here = dirname(fileURLToPath(import.meta.url));
const root = join(here, '..', '..', 'shlink-web-client', 'node_modules', '@shlinkio');
const bundles = [
  join(root, 'shlink-web-component', 'dist', 'index.js'),
  join(root, 'shlink-web-component', 'dist', 'settings-BOILmGcF.js'),
  join(root, 'shlink-frontend-kit', 'dist', 'index.js'),
];
const texts = bundles.map((f) => readFileSync(f, 'utf8'));

// 数据值（国家名/浏览器名等）识别：形如 KEY: "Value" 的大对象
const objRe = /=\s*\{\s*((?:[A-Za-z0-9_]{2,12}\s*:\s*"[^"]{1,40}",?\s*){5,})\}/g;
const dataVals = new Set();
for (const src of texts) {
  for (const m of src.matchAll(objRe)) {
    for (const [, v] of m[1].matchAll(/:\s*"([^"]*)"/g)) dataVals.add(v);
  }
}

// UI 文案候选
const uiRe = /"([A-Z][A-Za-z0-9 ,.'!?()/%&-]{2,60})"/g;
const counts = {};
for (const src of texts) {
  for (const m of src.matchAll(uiRe)) {
    if (dataVals.has(m[1])) continue;
    counts[m[1]] = (counts[m[1]] ?? 0) + 1;
  }
}
const sorted = Object.fromEntries(Object.entries(counts).sort(([a], [b]) => a.localeCompare(b)));
writeFileSync(join(here, 'expected.json'), JSON.stringify(sorted, null, 2) + '\n');
console.log(`候选 ${Object.keys(sorted).length} 条，出现 ${Object.values(sorted).reduce((a, b) => a + b, 0)} 处`);
```

```js
describe('replaceLiterals', () => {
  it('替换完整字面量', () => {

    const { code, counts } = replaceLiterals('const a = "Save"; const b = "Cancel";', dict);
```

- [ ] **Step 3: 实现 `scripts/i18n/replace-literals.mjs`**

```js
// 按字典替换代码里的英文字面量。只替换完整字面量，不做子串替换。
export function replaceLiterals(code, dict) {
  const counts = {};
  let out = code;
  for (const [en, zh] of Object.entries(dict)) {
    const literal = JSON.stringify(en);
    const replacement = JSON.stringify(zh);
    let n = 0;
    // 用 split/join 精确匹配完整字面量
    const parts = out.split(literal);
    n = parts.length - 1;
    if (n > 0) {
      out = parts.join(replacement);
      counts[en] = (counts[en] ?? 0) + n;
    }
  }
  return { code: out, counts };
}
```

- [ ] **Step 1: 写插件 `scripts/i18n/vite-plugin-i18n.mjs`**

```js
// vite 插件：构建期把上游产物与 src 里的英文字面量替换成中文。
// I18N_LANG=en 时不替换（出英文原版）。
import { readFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { dirname, join } from 'node:path';
import { replaceLiterals } from './replace-literals.mjs';

const here = dirname(fileURLToPath(import.meta.url));
const dict = JSON.parse(readFileSync(join(here, 'zh-CN.json'), 'utf8'));
const expected = JSON.parse(readFileSync(join(here, 'expected.json'), 'utf8'));

const TARGET_RE = /(@shlinkio\/(shlink-web-component|shlink-frontend-kit)\/dist\/|[/\\]src[/\\])/;

export function i18nPlugin() {
  const enabled = process.env.I18N_LANG !== 'en';
  const counts = {};
  for (const en of Object.keys(dict)) counts[en] = 0;

  return {
    name: 'rxlink-i18n',
    enforce: 'pre',
    transform(code, id) {
      if (!enabled) return undefined;
      if (!TARGET_RE.test(id)) return undefined;
      const { code: out, counts: c } = replaceLiterals(code, dict);
      for (const [k, v] of Object.entries(c)) counts[k] += v;
      return out === code ? undefined : { code: out, map: null };
    },
    buildEnd() {
      if (!enabled) return;
      const errors = [];
      for (const [en, exp] of Object.entries(expected)) {
        if (counts[en] !== exp) {
          errors.push(`  ${JSON.stringify(en)}: expected ${exp}, got ${counts[en]}`);
        }
      }
      if (errors.length > 0) {
        throw new Error(`i18n 断言失败（${errors.length} 条）：\n${errors.join('\n')}`);
      }
    },
  };
}
```
