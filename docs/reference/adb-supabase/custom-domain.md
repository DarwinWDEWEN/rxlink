# 如何为 AnalyticDB Supabase 项目添加自定义域名

> 来源：https://help.aliyun.com/zh/analyticdb/analyticdb-for-postgresql/support/how-to-add-a-custom-domain-name-for-an-analyticdb-supabase-project
> 存档日期：2026-10-28

以阿里云域名管理服务为例，说明如何用 **CNAME + CDN** 方式为 AnalyticDB Supabase 项目添加自定义域名。

## 前提条件

- 已创建 AnalyticDB Supabase 项目。
- **准备一个已在阿里云接入网站备案的自定义域名**。按域名归属选择备案路径：
  - 当前阿里云账号注册的域名：登录 [阿里云 ICP 代备案管理系统](https://bsn.console.aliyun.com/#/bsnApply/fc) 备案。
  - 其他阿里云账号注册的域名：建议用注册域名的阿里云账号完成备案。

  说明：
  - **中国香港和海外地域的自定义域名不需要备案。**
  - 不确定域名服务商 → [域名信息查询（WHOIS）](https://whois.aliyun.com/)。
  - 不确定域名是否属于当前阿里云账号 → [云解析 DNS 控制台](https://dns.console.aliyun.com/#/dns/domainList)。

- 已[开通 CDN 服务](https://help.aliyun.com/zh/cdn/activate-alibaba-cloud-cdn#task-187531)。

## 步骤一：配置域名信息

1. 登录 [CDN 控制台](https://cdn.console.aliyun.com/)。
2. 左侧导航 **域名管理** > **添加域名**。
3. 在 **业务信息** 区域配置 **加速区域**、**加速域名**、**业务类型**，其余保持默认：
   - 域名在中国内地完成备案 → 加速区域可选 **仅中国内地** 或 **全球**；未备案则选 **全球（不包含中国内地）**。
   - **加速域名** 填写自定义域名。

   说明：首次配置需验证域名归属，按 **DNS 配置引导** 添加归属 **TXT 记录**，回 CDN 页面 **点击验证**；配置完成后 DNS 侧会多出一条 `verification` TXT 记录。

## 步骤二：配置源站

1. **源站信息** 区域 > **新增源站信息**。
2. 配置：
   - **源站信息**：选 **源站域名**，**域名** 填写 **Supabase 项目的域名**。
   - **权重**：`100`。
   - **端口**：需要 HTTPS 访问时把 `80` 改为 `443`。
   - 其余默认。
3. **确定**。
4. 完成回源配置：
   1. **域名管理** > 选择目标域名进详情页。
   2. **回源配置** > **默认回源 HOST** 区域 > **修改配置**。
   3. 启用 **回源 HOST**，**域名类型** 选 **源站域名**（选中后下方展示 Supabase 项目的源站域名）。
   4. **确定**。

## 步骤三：（可选）配置 HTTPS

1. **域名管理** > 目标域名详情页。
2. **HTTPS 配置**。
3. **HTTPS 证书** 区域 > **修改配置**，按提示完成证书填写。
4. （可选）**HTTP/2 设置** 区域启用 HTTP/2。
5. （可选）**协议重定向** 区域配置，把 HTTP 自动跳转至 HTTPS。

> **重要**：如果单个 CDN 域名配置无法正常访问，可能需要同时配置主域名和 www 子域名。例如对 `example.com`：
> - 在 CDN 控制台分别配置 `example.com` 与 `www.example.com` 两条域名记录；
> - 在 DNS 控制台分别为两者添加 CNAME 记录。
>
> 完成上述配置后即可用自定义域名进行 HTTPS 访问，无需额外上传证书。

## 对本项目的含义（分析，非文档原文）

1. 官方文档给出的自定义域名路径**只有 CDN CNAME 回源**这一条，没有任何「把某个路径映射到某个函数」或「自定义路由」的配置项。因此短链 `https://s.example.com/AbC123` 能否命中 Edge Function，取决于 **CDN 的「重写访问 URL」规则是否支持正则捕获组透传路径** —— 这条不在本文档内，属 P0 验证项 1。
2. **每一个短链域名 = 一套「备案 + CDN 域名 + 证书 + 回源 HOST + CNAME」**，且可能还要额外配 www 子域。这就是「本期多域名」的真实成本：它是运维与合规工作量，不是代码复杂度。
3. 备案是中国内地加速区域的前置条件；若走**中国香港/海外地域**可免备案，但会牺牲内地访问延迟与可达性——这是一个需要产品侧权衡的分叉点。
4. 回源 HOST 必须是 Supabase 源站域名，意味着**函数内部看到的 `Host` 是 Supabase 域名**，短码所属域名要从 `x-forwarded-host` 取，而不是 `host`。跳转函数解析短码归属域名时依赖这一点 → P0 验证项 1 要顺带确认 CDN 是否传递 `x-forwarded-host`。
